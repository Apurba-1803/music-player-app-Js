This is a basic web application where users can:
1.Create multiple playlists
2.Add songs to selected playlists
3.View the list of songs in each playlist

🚀 Features
1.Create and name custom playlists
2.Add individual songs to a selected playlist
3.Switch between playlists to view their respective songs
4.Simple and clean UI with dynamic DOM manipulation using JavaScript

🛠️ Technologies Used
HTML
CSS
JavaScript (Vanilla)
